# 🧮 TEBEX CALCULATEUR 🧮

### Calculateur de frais Tebex FiveM — v2.0

---

## 📦 PRÉSENTATION 📦

Tebex Calculateur est un outil standalone Windows conçu pour les mappeurs et développeurs FiveM qui vendent leurs ressources sur Tebex. Il vous permet de savoir **exactement combien vous allez réellement toucher** après déduction de toutes les commissions, avant même de fixer votre prix de vente. Fini les mauvaises surprises au moment du retrait.

> **v2.0 — Mise à jour majeure** basée sur des retours personnels et les remontées de la communauté qui ont permis d'identifier les écarts de calcul de la v1.

---

## 🚀 FONCTIONNALITÉS CLÉS 🚀

💰 **CALCUL EN TEMPS RÉEL** Saisissez un montant ou utilisez le slider. Le résultat net s'affiche instantanément après déduction de toutes les commissions réelles.

🌍 **SLIDER TVA PAR PAYS** Sélectionnez le pays estimé de votre acheteur. Paliers aimantés de 0% (USA) à 27% (Hongrie MAX). Défaut : 25% pour une estimation prudente.

🔄 **CALCULATEUR INVERSÉ** Entrez le montant que vous voulez **réellement toucher** et l'appli calcule automatiquement le prix HT à fixer sur Tebex.

📊 **DÉCOMPOSITION VISUELLE** 4 barres colorées + camembert interactif : Frais plateforme / Frais passerelle / TVA / Ce que je touche.

📋 **GRILLE TARIFAIRE** Consultez en un clic toutes les commissions avec la source officielle docs.tebex.io.

---

## ⚠️ MARGE D'ERREUR

Certains frais (notamment les frais de passerelle) varient selon le moyen de paiement de l'acheteur (carte, PayPal, Apple Pay...). Un écart de **±0,50 € à ±1 €** entre le résultat affiché et le montant réellement reçu est normal. Prenez toujours cette marge en compte lors de la fixation de vos prix.
